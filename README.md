# Eletronic-Vehicles-Analysis
# 🚗 Electric Vehicles Analysis Dashboard

This repository showcases an interactive Tableau dashboard analyzing trends in electric vehicle (EV) registrations, models, and distributions across different regions.

🔗 [View the Live Dashboard on Tableau Public](https://public.tableau.com/app/profile/qing.guo1038/viz/EletronicVehiclesAnalysis/Dashboard3)

## 📊 Dashboard Preview

[EV Dashboard Screenshot](assets/ev-dashboard-preview.png)

## 📄 Project Description

This dashboard highlights:
- Total EVs registered by region and vehicle type
- Temporal trends in EV adoption
- Comparison of battery range, model popularity, and drivetrain types

It leverages open data to provide a clear visual understanding of how EV usage is evolving.
